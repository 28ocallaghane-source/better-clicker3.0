# Changelog

All notable updates to Better Clicker 3.0 will be recorded here.

## Version 3.0.0 — Initial Release

### Features

* Added the main clicker game.
* Added click-power upgrades.
* Added power multiplier upgrades.
* Added auto-clickers.
* Added upgrades to increase auto-clicker speed.
* Added rebirths that reset progress and provide permanent bonuses.
* Added evolutions unlocked after every 5 rebirths.
* Added automatic saving in the browser.
* Added an option to reset saved progress.

### Planned Updates

* Balance upgrade prices and rewards.
* Add more evolutions and rebirth bonuses.
* Improve the game's appearance and animations.
* Add new upgrades and achievements.
